# Travel photo folders

Create a folder for each trip here, such as `travel/photos/tokyo-japan/`, and put that trip's images inside it. Then add their relative paths to the matching entry in `../data.js`, for example:

```js
photos: ['travel/photos/tokyo-japan/arrival.jpg']
```

For each new place, add its details to `data.js` and store its images in this folder. After committing and pushing both changes, GitHub Pages will publish the new pin for every visitor.
