Operating System Design · Spring 2026

Mini Custom Kernel

Over the semester for CMU's Operating System Design and Implementation (15-410) course, we built a bare-bones, Unix-like kernel in C!

We implemented core kernel functionality including:
Virtual memory (paging and page fault handling), Syscalls for process lifecycle management (fork, exec, wait), Concurrent kernel processes and synchronization, A preemptive thread scheduler, I/O syscalls

Shoutout to my project partner Victoria: through sickness, sweat, and tears we made Meat with the Sauce. While far from a good operating system, it is still an operating system 😛
